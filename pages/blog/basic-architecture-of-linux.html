A brief introduction to Basic architecture of Linux

First things first -- Linux is not an operating system. Linux is a kernel which is a core part of the operating systems, managing hardware, software and processes. The term Linux is often used interchangeably with its many distributions like Ubuntu, Fedora, Debian, Manjaro, Arch Linux. However they are complete operating systems built on top of Linux kernel.

What is a Kernel?

The kernel is the central component of an operating system that manages communication between hardware and software. It is responsible for:

  • Memory management: Allocating and managing RAM.
  • Process management: Handling processes and multitasking.
  • Hardware interaction: Communicating with hardware via device drivers.
  • Security: Managing user permissions, access control, and system integrity.

Kernel provides an interface between user-level applications and hardware, abstracting the complexities of hardware interactions.

What happens when you power on your PC?

Power-on process: When you start your computer, the BIOS runs first, which looks for a bootable device (usually the hard drive or SSD).

The Bootloader (e.g., GRUB in many distros) loads the kernel into memory (RAM). The kernel is the first program executed by the computer.

Once the kernel is loaded, it initializes hardware and mounts the file system. After that, the kernel hands control to the init system, which starts up user processes and applications.

RAM: During the boot process, the kernel is loaded into RAM so that it can directly interact with the hardware and manage the system. This is important because RAM is faster than storage devices, ensuring smooth system operation.

What is a distribution?

A Linux distro is an OS built around the Linux kernel and includes software like user interfaces, utilities, and package management tools. The kernel remains the same across all these distributions. The main difference lies in the packages and software provided by each distribution.

What are package managers?

Linux doesn't come with an app store like macOS or Windows. A package manager is a tool that allows you to easily install, update, and remove software on your system. When you use a package manager to install software, it fetches the software from a repository, installs dependencies, and configures the application.

Different distributions use different package manager formats:

  • Debian-based (e.g., Ubuntu) use .deb packages and the apt package manager.
  • Red Hat-based (e.g., Fedora) use .rpm packages and the dnf or yum package managers.

User Space vs. Kernel Space

Linux can operate in two spaces:

  • Kernel Space: This is where the kernel runs and has full access to the hardware. Any code that runs in kernel space can directly interact with the hardware.
  • User Space: This is where normal user applications run. These programs do not have direct access to hardware and interact with the kernel through system calls.

This ensures that user programs cannot interfere with the core functions of the OS, providing a level of security and stability.

Desktop Environments

A desktop environment is the GUI that allows you to interact with your Linux system using windows, icons, and menus. Different Linux distros can come with various DEs:

  • GNOME: One of the most popular DEs, especially for distributions like Ubuntu. Known for its simplicity, doesn't offer much customization.
  • KDE Plasma: A more customizable DE, known for being feature-rich. Offers a look and feel similar to Windows, with lots of settings to tweak.

Permissions

Linux is built with strong user and file permissions. Each file and directory has a set of permissions that dictate which users or groups can read, write, or execute them. You can view and modify permissions using ls -l (to list permissions) and chmod (to change them).

If you understand the basic architecture of Linux, it can open up lots of possibilities. Keep experimenting, learning, and don't hesitate to dive deeper into the rich world of Linux!
